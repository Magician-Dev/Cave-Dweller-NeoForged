# Cave Dweller NeoForged
This is a repository for the Cave Dweller NeoForged minecraft mod, which is a remake of the original Cave Dweller mod by Gargin, updated to NeoForge 1.21.1 and with some extra features. As of now, the mod is very much a work in progress, but I wish to make it as solid as I can (where's the fun when there are countless bugs?) which might take a good while due to me being lazy or just not a coding master.

This mod is currently being developed with MCreator 2026.2 alongside custom plugins and a bit of custom coding. The plugins used include: GeckoLib Reborn (for the animations), Forge mixins (used to change some stuff about the dweller), Pehkui (used for hitbox scaling), VCS (for github) and ArrayLists (for managing player lists).

Also, keep in mind the version of the Pehkui plugin that I am using is a modified version of krissedout's Pehkui for MCreator plugin to meet the requirements to work on MCreator 2026.2 properly.
